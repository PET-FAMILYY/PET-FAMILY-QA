## Projeto

O **Pet Family** é um ecossistema de cuidado contínuo que conecta tutores, pets e clínicas veterinárias, promovendo acompanhamento preventivo, personalização por perfil clínico e recorrência de consultas — desenvolvido em resposta ao Challenge CLYVO VET 2026.
